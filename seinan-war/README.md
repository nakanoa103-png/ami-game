# 西南戦争 1877

明治10年（1877年）、西郷隆盛を擁して挙兵した私学校党を率い、明治政府に挑むブラウザ用の戦略シミュレーションゲームです。一人用で、政府軍はコンピューターが動かします。

熊本城に固執して史実どおり行き詰まるか、抑えを残して東上するか、長崎で蒸気船を奪って海から大阪・東京を突くか。約7か月の戦いの行方を選べます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます。インストールもサーバーも要りません。

GitHub Pages で公開している場合は、`https://<ユーザー名>.github.io/<リポジトリ名>/` からも遊べます。

1. 地図で拠点を選び、動かす部隊にチェックを入れます。
2. 右の進軍先ボタンで進軍・攻撃します。地図の点線の輪を押すと、行き先の様子を見てから進軍を確定できます。
3. 地図左上の「ターン終了」を押すと、政府軍が動いて次の旬（約10日）に進みます。

詳しいルールは、ゲーム内の「遊び方」でいつでも確認できます。

## 勝敗

| 結末 | 条件 |
|---|---|
| 勝利（政府瓦解） | 政府威信を0にする |
| 勝利（東京入城） | 東京を占領する |
| 勝利（和議成立） | 政府威信を35以下のまま5ターン保つ。または最終ターン（第23ターン、明治10年9月下旬）を終えた時点で35以下 |
| 引き分け（西郷復権） | 大久保利通からの講和の申し入れを受ける |
| 敗北 | 西郷が討ち死にする／最終ターン終了時に政府威信が36以上 |

## 主なルール

- **政府威信**：町の占領や戦いの勝利で下がり、敗北や鹿児島の失陥で上がります。進軍も勝利も占領も熊本城の包囲もないターンが過ぎると、少しずつ戻ります。
- **熊本城**：強襲は分の悪い博打です。3,000以上で囲み続ければ糧食が尽きて開城します。落とした後は防御×1.5の拠点になります。
- **補給線**：弾薬は鹿児島から西郷の本営まで、支配地が陸続きのときだけ届きます。
- **私学校の精鋭**：最強ですが補充できません。鹿児島で徴募はできますが、質は落ちます。
- **海路**：一部の航路は蒸気船が必要です。長崎を2,000以上で攻め取ると蒸気船を奪える可能性があります。政府海軍に捕まると、船団の大きさによらず1,000を失って引き返します（少数なら半数）。
- **退却**：負けたら街道の隣へ退きます。逃げ道がなければ港から船で逃れるか、囲みを破るしかありません。政府軍は西郷の本営に迫ると、別働隊で退路を塞ぎに来ます。
- **呼応と事件**：熊本隊・協同隊、日向諸隊、中津隊、福岡党、土佐立志社などが戦況に応じて加わります。勅使柳原前光の来訪、島津久光の擁立、大久保の密使といった史実にちなむ事件も起きます。ほかにも、条件がそろうと起きる隠し事件があります。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `data.js` | 地図・海路・増援の予定・各種の数値 |
| `game.js` | ゲームの処理（戦闘、政府軍の思考、事件、画面の描画） |

外部のライブラリや画像は使っていません。

## 数値を調整するには

兵の強さ、増援の予定、勝利条件のライン、事件の確率などは `data.js` にまとまっています。

ファイルを更新して公開するときは、`index.html` の読み込み部分にある版番号（`?v=21` など）を1つ上げてください。上げないと、ブラウザが古いファイルを使い続けることがあります。

## 史実との関係

部隊名、指揮官、事件は史実をもとにしていますが、ゲームとしての単純化と、史実にない「もしも」を含みます。兵力や日付も、遊びやすさのために丸めています。
