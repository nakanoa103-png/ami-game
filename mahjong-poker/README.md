# 麻雀ポーカー / 五枚勝負

麻雀牌136枚を使い、1人＋CPU3人で遊ぶ五枚勝負のブラウザゲームです。麻雀の「引く・捨てる・鳴く」と、ポーカーのような役比べ・賭けを組み合わせています。

## 起動

このフォルダで `node server.cjs` を実行し、http://127.0.0.1:8784/ を開きます。ES Modulesを使用しているため、`index.html` の直接ダブルクリックではなくHTTP経由で起動してください。

全ルールはゲーム画面の「遊び方・役一覧」にも表示しています。

## 現行ルール

### 対局の流れ

- 花牌なしの136枚を使用。四人とも5枚の手牌で始め、持ち点は各25,000点です。
- 自分の手番では1枚引き、1枚捨てて手牌を5枚に戻します。引く前、または自分の捨て牌へのロン・鳴きがなかった後に、勝負を宣言できます。
- 引いた牌を含めて上がれる形ができた場合は、捨てる牌を選んでから「ツモ上がり」か「その牌を捨てる」かを選びます。
- リーチ・振り聴はありません。チーは直前の手番の人からのみ、ポンとロンは誰からでもできます。カンはありません。各自が鳴ける組は1つまでです。

### 上がれる形

ワンペア単独では上がれません。以下の形は上がれます。

- ワンペア＋同じ種類の3枚順子。例：11萬＋345筒。
- 2ペア以上。2ペアの5枚目は無関係な牌でも構いません。
- 3カード、ストレート、フラッシュなど、ほかのポーカー役。

倍率役やドラだけでは上がれません。ワンペア＋順子は上がれますが、役比べでの基本ランクは「1ペア」です。

### 役の強さ

弱い順です。同じ役なら、役を作る牌の組から比べ、その後に残りの牌を比べます。

1. 1ペア
2. 2ペア
3. 3カード
4. ストレート
5. フラッシュ
6. フルハウス
7. 4カード
8. ストレートフラッシュ
9. 5カード
10. 国士無双

- 数牌の同じ数字は、萬子＜索子＜筒子です。字牌は数牌より強く、東＜南＜西＜北＜白＜發＜中です。
- ストレートは数牌の連続する数字、または字牌の連続で成立します。数牌と字牌は混ぜません。
- フラッシュは同じ種類の牌5枚です。萬子・索子・筒子・風牌・三元牌をそれぞれ別の種類として扱います。
- ストレートフラッシュは、ストレートとフラッシュを同時に満たす手です。数字に特別な「ロイヤル」の条件はありません。
- 5カードは、萬子・索子・筒子を問わず同じ数字が5枚そろった手です。
- 国士無双は、萬子・索子・筒子から一・九を各1枚、風牌を1枚、三元牌を1枚集めた手です。

### 勝負・ツモ・ロン

勝負を宣言すると全員の手牌を公開し、上がり条件を満たす手の中で最も強い人が勝ちます。宣言者が勝てばほかの3人から受け取り、待ち受けた人が勝てば宣言者から受け取ります。最強の手が完全同点なら点数移動なしです。

ロンは、捨て牌1枚と手牌4枚で有効な上がり形を作り、元の手牌より役比べで強くなるか、元の手牌に順子＋対子がなく、元と同じ以上の役ランクで新たに順子＋対子を完成した場合にできます。鳴いて固定した牌は入れ替えられません。複数のロン候補があれば最も強い手を優先し、同点なら振込者から手番が近い人が優先です。

ツモ上がりを選んでも、ほかにより強い有効な手があれば返り討ちになります。返り討ちは宣言者からの直接精算で、役・ドラ倍率は使いません。親の1.5倍は適用されます。

### 役の倍率

倍率役は成立した中で最も高いものを使います。ドラは役倍率に加算します。勝負宣言者の勝利とロンに役・ドラ倍率が適用されます。待ち受け側の返り討ちは倍率1です。

- 平和 ×1：同じ種類の3枚順子＋対子。鳴きや字牌の対子も可。
- タンヤオ ×2：一・九・字牌を含まない。
- ホンイツ ×2：一種類の数牌と字牌だけで構成し、字牌の対子または刻子を含む。手牌全体を対子＋三枚組に分けられること。
- チャンタ ×2：順子＋対子に分けられ、両方の組に一・九・字牌が関係し、数牌と字牌の両方を含む。
- 純チャン ×3：順子＋対子に分けられ、両方の組に一・九が関係し、字牌を含まない。
- 同数2ペア・同数フルハウス ×3：異なる種類の数牌で同じ数字の組を作る。2ペアは2＋2＋自由牌、フルハウスは3＋2。
- 字一色 ×4：5枚すべて字牌。
- 緑一色 ×4：發を2枚以上含め、發の対子＋索子の刻子または三枚順子、もしくは發の刻子＋索子の対子を作る。孤立牌は不可。
- 小三元 ×5：白・發・中の2種類でフルハウス。
- 小四喜 ×5：東・南・西・北の2種類でフルハウス。
- 5カード ×3：萬子・索子・筒子を問わず同じ数字を5枚。
- 国士無双 ×6：数牌の一・九を各種類から1枚ずつ、風牌1枚、三元牌1枚。
- ドラ：順子・対子・刻子・4枚組などの有効な組に使われたドラ1枚につき＋1。孤立したドラは加算しません。

### 賭け点と精算

賭け点は供託しません。精算額の基準は勝者の賭け点です。各支払者が実際に支払う上限は、その人自身の賭け点です。持ち点全部を賭けることもできます。

最低賭け点は東1局の500点から始まり、局が進むごとに500点ずつ上がります。同順位を除き、順位が上の人は下位の人より100点以上多く賭けます。持ち点が足りない場合は、その持ち点までです。賭け点は精算前なら変更できます。

勝者が勝負を仕掛けた場合、基本額は「勝者の賭け点 ×（最高の役倍率＋有効ドラ枚数）」です。親が勝てば、さらに1.5倍になります。宣言した人が勝てばほかの3人から、ロンなら振込者から受け取ります。

ツモの基本額は上の式で出した総額です。親ツモは子3人が均等に負担し、子ツモは親が総額の半分、ほかの子2人が4分の1ずつ負担します。その後、各人の賭け点を上限として支払額を決めます。親の1.5倍を含む分配では25点単位の移動が発生することがあります。

### 半荘と終了条件

- 東場4局、南場4局を基本に進行します。親が勝った局は同じ親・同じ局で連荘します。本場の追加点はありません。
- 南4局で全員が30,000点未満なら西入します。西4局でも全員が30,000点未満なら北入します。北4局で終了します。
- 誰かが精算後に0点以下になった場合も終了します。
- 半荘終了時のトップに20,000点のトップ賞を加算します。西入・北入の判定はトップ賞を加える前に行います。
- 開始時に半荘数を選べます。初期値は3回です。各回の終了時の持ち点を累計し、最後に総合順位を決めます。

## 確率

以下は交換前に無作為に配られた5枚を対象に、136枚の物理牌から組合せを数えたものです。実戦中の交換・鳴き・選択を含む完成率ではありません。

- 全5枚組合せ：C(136,5) = 359,933,112。
- ストレート：1,247,232通り（0.3465%）。
- フラッシュ：1,136,136通り（0.3157%）。
- ストレートとフラッシュの重複：15,360通り（0.0043%）。
- 重複するストレートフラッシュを除くと、ストレートは1,231,872通り、フラッシュは1,120,776通りです。フラッシュの方が少ないため、ストレートより強くしています。
- 国士無双：98,304通り（約0.0273%、約3,660回に1回）。
