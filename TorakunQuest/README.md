# 虎くんクエスト

ブラウザだけで遊べる、ドラクエ風の短編RPGです。

## 起動

`torakun_quest.html` をダブルクリックしてブラウザで開きます。追加インストールは不要です。

## 操作

- 移動：矢印キー / WASD / 画面の方向ボタン
- 決定・話す・調べる：Z / Enter / Aボタン
- メニュー・戻る：X / Esc / Bボタン

## 差し替え場所

ゲーム内容は `data/game-data.js` にまとまっています。

- `story`：オープニングとエンディング
- `maps`：マップ、NPC、移動先
- `monsters`：敵の名前、画像、能力
- `items`：道具
- `spells`：呪文
- `growth`：主人公の成長

画像は `images` フォルダーに置き、モンスターの `image` に相対パスを指定します。

```js
slime: {
  name: "スラミン",
  image: "images/slamin.png",
  hp: 8,
  attack: 6,
  defense: 2,
  exp: 3,
  gold: 4
}
```

## マップ記号

| 記号 | 内容 |
| --- | --- |
| `.` | 草原 |
| `,` | 道 |
| `T` | 木 |
| `M` | 山 |
| `H` | 家 |
| `~` | 水 |
| `#` | 洞窟の壁 |
| `-` | 洞窟の床 |
| `g` / `c` / `E` | マップ移動地点 |
| `C` | 宝箱 |
| `B` | ボス |

マップの各行は、必ず同じ文字数にします。`warps` の座標は左上を `(0, 0)` として指定します。

## ファイル構成

```text
TorakunQuest/
├─ torakun_quest.html  # ゲーム入口
├─ css/game.css        # 画面デザイン
├─ js/game.js          # ゲーム処理
├─ data/game-data.js   # 差し替え用ゲームデータ
└─ images/             # モンスター画像
```

進行状況はブラウザ内に保存されます。タイトル下部の「セーブデータを消す」で初期化できます。
